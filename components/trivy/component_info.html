Trivy Operator

Kubernetes vulnerability scanner operator. Automatically scans all workloads for CVEs (VulnerabilityReports), misconfigurations (ConfigAuditReports), and exposed secrets (ExposedSecretReports). Runs as an operator that watches for new/updated pods and generates reports as CRDs.

Architecture

Trivy Operator - Watches pod events, triggers scans on new/updated workloads
VulnerabilityReports - Per-container image CVE scan results (CRD)
ConfigAuditReports - K8s misconfiguration findings (CRD)
ExposedSecretReports - Hardcoded secrets detected in images (CRD)
OpenSearch Exporter - CronJob (every 30min) pushes reports to OpenSearch via bulk API

Links

Link Direction Generated Output
Prometheus → Trivy Inbound Generates service-monitor.yaml for Prometheus scraping
Trivy → OpenSearch Outbound Deploys CronJob exporter that reads Trivy CRDs and pushes to OpenSearch via bulk API every 30 minutes. Supports same-stack and cross-stack (external) OpenSearch.

OpenSearch Exporter (trivy-opensearch link)

When linked to OpenSearch, a CronJob runs every 30 minutes and exports three report types:

Report Type K8s CRD Fields Exported
Vulnerabilities vulnerabilityreports vulnerability_id, severity, package, installed_version, fixed_version, score, image, namespace, resource
Config Audit configauditreports check_id, severity, title, description, category (only failed checks)
Exposed Secrets exposedsecretreports rule_id, severity, title, category, target, match

All documents include stacktic_system field for multi-stack filtering. Index pattern: trivy-YYYY.MM.DD. Uses MD5-based document IDs for deduplication.

Cross-Stack (External) OpenSearch

Scenario Endpoint Port
Same stack (is_external: false) https://opensearch-cluster-master.{ns}.svc.cluster.local 9200
External stack (is_external: true) https://{remote_host} 443

Glossary

Reference
Terms, defined once

Most confusion about Stacktic is vocabulary. These are the words that carry a specific meaning here.

TermMeaning
StackOne system, as a graph. The unit of version, duplication and rollback
ComponentOne technology instance in a stack. Its type selects the generation logic
Sub-componentA resource a component owns — a database, bucket, topic, queue, client, model. A node in its own right
LinkA typed, directed edge. Named sourceType-targetType. Generates real configuration on both sides
AttributeA value on a component, a sub-component or a link. The only place configuration lives
GraphComponents, sub-components, links and attributes together — the complete description of a system
Stack metadataThe graph written as data into your stack repository; what the agent measures against
BuildRegenerate the whole stack repository from the graph
PushRegenerate only the files the changed attributes can affect
Impact mapPer-component mapping from an attribute to the generated files it can affect. What makes a push small
OverlayAn environment's differences from the shared base
Declared stateAnything in the graph — components, links, attributes, system users, routes, policies
Runtime dataAnything an application wrote — a ticket, a file, a row. Not in the graph, and should not be
DriftRuntime state that no declaration accounts for
Stack agentThe component that measures the running system against the graph
Link validationProving a declared edge layer by layer: wiring, secret, network, access, protocol
Probe fileA technology's own protocol check, shipped with its template and collected into the agent
ScanA scored measurement of one dimension of the running system
FindingOne issue from a scan, with a stable identity, a first-seen date and evidence
DeltaThe classified difference between a run and the previous run of the same type
AttestationThe hashes and context that fix what a run measured, and against which state
BaselineA labelled run. Drift is measured from a baseline; change is measured from the previous run
ReviewA named person's recorded position on a control or a link the automation could not pass
GateA record of human approval that something else waits on before it runs
MCPModel Context Protocol — how an AI client talks to the platform
DispatcherAn MCP tool taking an action enum, with a built-in help action
Knowledge layerWhat the MCP reads to answer correctly — catalog, semantics, patterns, recipes, playbooks
RecipeA declarative upgrade or migration procedure for a component
BlueprintA recognisable arrangement of components and links. Not a special mode

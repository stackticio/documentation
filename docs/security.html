Security, layer by layer

Security
Every control comes from the graph, and every control is measured

Security in Stacktic is not a separate product bolted onto the stack. Each control is a component, a sub-component, a link or an attribute. It is generated with the topology, regenerated when the topology changes, and measured by the stack agent against what the graph declares.

Why this shape matters​

A control follows the topology. Add a link and its network path, its route policy and its monitoring appear together. Remove it and they go at the next build. There is no window in which the security rules describe last month's system.

A control is versioned with the stack. It is in the diagram's history, in a diff between two versions, in a duplicated environment, and in a rollback.

A control is measured, not assumed. The stack agent runs the scan that matches each layer and records the result with the metadata commit it judged. "We enforce that" becomes a run anyone can repeat.

Tune, never remove​

Hardening starts with the components' own attributes: an application's security_features, the OPA policy sub-components and their modes, the options on each gateway route. When a policy blocks something the stack needs, the policy is tuned to the stack — a scope, an exclusion, a mode — not removed.

An AI client connected to the stack's MCP server can produce the plan with security_tuning(action='plan'). It reads the stack and returns, for every item, the attribute, its current and recommended value, why, what it can break, and the exact call that changes it. It never writes. Each item has a class:

ClassMeaning
critical_reviewDangerous today; a person confirms before anything changes
apply_nowNear-zero risk, with the residual condition stated
stagedDepends on how the application behaves at runtime: change it on a non-production environment first
needs_inputThe value is not in the design (office or VPN address ranges, an identity client) and has to come from you

Apply what you approve, build, deploy, and confirm with the admission scan.

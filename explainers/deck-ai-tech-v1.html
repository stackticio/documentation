{ STACKTIC }WHY IT BREAKS
03 — 08
compliance

Compliance cannot survive a non-deterministic pipeline. An auditor does not ask what the model intended. They ask which control was enforced, on which change, on which date — and want the artifact. Free-form generation cannot produce that. A blueprint can.

AI ALONE — WHY IT FAILS AN AUDIT
The control isn't reproducible. Re-run the prompt, get a different manifest. The approved version and the shipped version are not the same object.
Controls are per-file, not per-graph. TLS on one service, plaintext on the link next to it. Nothing derives the rules from the real topology.
It's a point in time. A PDF from the quarter you were audited, describing a cluster that has changed 400 times since.
No evidence trail. Prompts and chat transcripts are not audit artifacts. There is no scored, dated, signed record of the scan.
Drift is invisible. Nothing compares what is running against what was approved, so the gap only surfaces during the audit.
PCI DSSISO 27001HIPAAGDPR
verdict: "we believe we are compliant"
evidence: a conversation
WITH STACKTIC — COMPLIANCE BY CONSTRUCTION
The control lives in the blueprint. Same input renders the same manifest, byte for byte. Reviewed once, enforced on every render.
Rules are derived from the graph. Network policies, TLS, secrets and SSO come out of the declared links — not out of someone remembering to add them.
Checked on every change, not once a quarter. The gate runs before the change reaches the cluster.
Evidence is an artifact. The in-cluster agent scans the live stack, scores it, and commits the result to git — dated, diffable, exportable.
Drift is a finding. Running state is compared to the declared state continuously, and the delta is reported like any other failure.
PCI DSSISO 27001HIPAAGDPR
verdict: scored, per change, per control
evidence: an artifact in your repository
›Security you can't reproduce isn't security. It's a story.

{ STACKTIC }THE FLOW
05 — 08
prompt → proof

Prompt → Stacktic → code → agent → cluster → validation → back. A closed loop. Nothing is invented in the middle, nothing reaches the cluster unchecked, and the result of every change flows back so the next prompt is grounded in what is actually running.

The brain is the graph, not the modelStacktic answers from your declared stack — components, attributes and links — so two identical requests produce two identical renders.
The gate is in the path, not beside itPolicy, compatibility and compliance checks run between the code and the cluster. Failing the gate means the change does not move.
The loop closesScans and live state are written back as artifacts, so the next prompt starts from reality instead of from the model's imagination.
›Every arrow is deterministic. That is the whole trick.

🎛️ How Tuning Parameters Affect Your ROI

🔴 Incident Reduction %
What it controls: How much Stacktic reduces security incidents and incident response time through automated security policies (OPA), network segmentation, and centralized monitoring.
💡 Impact: Each 10% increase = +$25K/year in risk reduction value
⏰ Downtime Reduction %
What it controls: Reduction in unplanned downtime through HA configurations, automated failover, health checks, and self-healing infrastructure.
💡 Impact: Each 10% increase = +$11K/year in business continuity value
💾 Vendor Lock-in Avoidance %
What it controls: Cost savings from K8s-native alternatives (CloudNative-PG, Strimzi, Redis Operator) vs cloud-managed services (RDS, MSK, ElastiCache).
💡 Impact: Each 10% increase = +$10K/year in infrastructure savings
🏚️ Legacy System Removal %
What it controls: Percentage of legacy systems that can be migrated to K8s-based architecture, eliminating maintenance costs over 5-year horizon.
💡 Impact: Each 10% increase = +$4K/year in legacy elimination savings
🎯 Pro Tip: Start conservative with 30-40% assumptions. Run a pilot with 2-3 apps, measure actual results, then adjust parameters based on real data. Most enterprises see 40-60% improvements in Year 1, ramping to 70-80% by Year 3.

📊 Understanding the Calculation

💰 CAPEX (Capital Expenditure)

What is it? One-time costs to set up NEW applications

When? Year 1 only (setup phase)

Includes:

  • 📐 Day 0: Architecture & Design (4 tasks)
  • 🏗️ Day 1: Infrastructure Setup (9 tasks)

Applied to: 3 new apps

🔄 OPEX (Operating Expenditure)

What is it? Recurring costs to maintain EXISTING applications

When? Every year (ongoing operations)

Includes:

  • ⚙️ Day 2: Operations & Maintenance (16 tasks)
  • 🔁 Tasks run 1-12 times per year

Applied to: 10 existing apps
